## Results

- `npm test`: 24 files, 407 tests pass. `npm run build` passes; the docs text is in 75 small chunks loaded when the panel first opens, not in the main bundle.
- Badge: real file shows 0.000001, equal to `max_diff_deg`; the pending (mock, `checked_at` null) and unavailable (missing, broken or incomplete file) states are covered by unit tests, not seen in the browser.

## Limits

- The dialog behaviour is checked in a browser, not in `npm test`: the tests run in node with no DOM, and adding a DOM library was not worth a new dependency.
- The panel shows the notes as the files say them, including tool names written in several ways ("Claude Code (Opus 5.5)", "Claude Code (Claude Opus 5.5)").
- Tables in AI-use files that are not AI-use rows (design choices, limits, results) are not drawn in the panel; each task links to its full notes on GitHub.
- Second delivery at M3 (`t16-about-b`): new files in `docs/` are picked up at build time; rerun the coverage tests and recheck the panel.
