## Limits

- The dialog behaviour is checked in a browser, not in `npm test`: the tests run in node with no DOM, and adding a DOM library was not worth a new dependency.
- The panel shows the notes as the files say them, including tool names written in several ways ("Claude Code (Opus 5.5)", "Claude Code (Claude Opus 5.5)").
- Tables in AI-use files that are not AI-use rows (design choices, limits, results) are not drawn in the panel; each task links to its full notes on GitHub.
- Second delivery at M3 (`t16-about-b`): done; results in the row above. `npm test`: 51 files, 782 tests pass. `npm run build` passes, with 138 docs chunks (68 + 70 files).
- A file merged after this delivery is still picked up when the site is built; only a new layout the parser doesn't read would need a change (`t16-about-c`), and the coverage tests in `about.test.ts` fail if that happens. T17's notes are the ones still to come.
- The tool names list repeats near-duplicates as the files write them (see above), and some rows put two tools in one cell.
