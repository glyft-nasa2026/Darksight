## Step 5: the person's QuickMap check

The contact sheet is made by `cd web && node scripts/quickmap-sheet.mjs` into
`data-prep/raw/quickmap/index.html` (not committed), with QuickMap's Nomenclature layer on, so
each picture names the features. Per site: a wide view, zoomed out until the whole named feature
fits (200 m per pixel, 400 for Nassau F), and a close view at 51.2 m per pixel. Each picture is
taken with the mouse on the pin, so its LAT/LON readout is the pin's, and the script checked that
the map moved and that this readout is the site. That is not the F12 check: a person looks at
each picture and confirms the pin is on its named feature.
