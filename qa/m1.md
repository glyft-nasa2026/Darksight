### F3 detail

Method: each case's latitude, longitude and time were entered into the site's own input boxes
from the console (setting each box and firing its input, change and Enter events), so the site
ran its normal path for each case; typing itself is covered by F1, and the first seven cases had
also been typed by hand earlier with the same numbers. The readout shows altitude to 2 decimals
and azimuth to 1, so the full-precision values were read from the sky panorama's "Sun now" and
"Earth now" markers, which the page draws from the same numbers. For every case the script waited
until the address bar showed that case's site and time (and any decade file had loaded), then
checked the markers against the readout's rounded values to make sure the reading belonged to that
case. Azimuth differences are taken round the circle. Limitation: the fixtures are for a point on
the surface; at -89.5 the site adds the height map's ground and a 2 m eye height, which moves
Earth's direction by well under 0.001°.
