M2 completed the first-time user exploration, Firefox compatibility check, real-phone compatibility check and all six F12 QuickMap coordinate checks.

The intentional Nudge panel overlap was accepted through D1. The map-label contrast issue from M1 was not remeasured in M2; it was fixed afterwards in #116 (see `qa/m3.md`).

The full F1–F19 feature set was not independently retested during M2, so this report does not claim that every feature passed a second round.
